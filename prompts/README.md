# Prompts vault

Откройте `prompts/` как Obsidian vault.
- `services/<slug>/<slug>.md` — copy-ready промпты на каждый из 10 услуг (тёмный `#171A20` / светлый `#D1D5DB` + MOTION A/B)
- `Attachments/<slug>/` — сюда перетаскивайте `raw-image.png` / `raw-video.mp4` прямо в Obsidian

Генератор: `python scripts/generate_animation_prompts.py`
